API chỉ trả về danh sách các event mà mentor được assign thông qua bảng category_mentors, nghĩa là mentor chỉ có thể xem các event và category mình phụ trách. Response nên bao gồm các thông tin cơ bản của event như eventId, title, status và danh sách category được assign. Nếu token không hợp lệ hoặc thiếu token thì trả về unauthorized, nếu user không phải mentor thì trả về forbidden access.
